# Autoría, autorización académica y aviso de almacenamiento

## Desarrollador

Este proyecto fue desarrollado por **Edwin Bolaños** como aplicación académica enfocada en modelos de ecuaciones diferenciales ordinarias de primer orden.

## Autorización concedida

Edwin Bolaños autoriza al profesor **Tito Amauryt** para publicar, usar, presentar, adaptar, modificar, enseñar, compartir, distribuir y reutilizar este proyecto con fines académicos, pedagógicos e institucionales.

La autorización incluye:

- usar el proyecto en clase;
- explicarlo a otros estudiantes;
- publicarlo en plataformas educativas;
- adaptarlo para ejercicios o talleres;
- modificar interfaz, textos, rutas o fórmulas;
- usarlo como base para enseñanza o demostraciones.

## Cookies y almacenamiento local

La aplicación no usa cookies de seguimiento, publicidad ni analítica invasiva. Solo utiliza `localStorage` para recordar que el usuario aceptó el aviso legal. Esta información permanece en el navegador y no se envía a terceros.

## Alcance académico

La aplicación es una herramienta de apoyo educativo. Sus resultados deben interpretarse como planteamientos y cálculos orientados a explicar modelos matemáticos. El docente puede complementar los pasos con demostraciones adicionales.
